## 0. 왜 T4인가 — 표시 트랙 종료 (T6·T7)

|---|---|---|

| T7 v5 미판독 시험셋 high 43 | 0.535 [0.389, 0.675] — 사전 기준 하한 0.40 미달 → **멈춤** | [측정, 구현 세션 판독] |

결론: 1단계 신호는 **있고 없음**만 본다 — "구조값이 원문과 같은 내용인가"(T6 X 8건: 다른 인물의 사물 ID, 빚↔예금, 방향 반대)는 원리상 못 잡는다. T4가 그 표적이다.
교훈 두 가지를 아래에 반영한다: (1) 판정 질문을 **유용성이 아니라 충실성**으로 좁힌다 — '배경 수치' 같은 가치 판단이 라벨에 들어오지 않게. (2) 맹검은 층·위치 열까지 가린다.

## 1. 과제

- **단위 = 추출 항목 하나.** 네 종류: `state_changes[]`(판정 대상은 `to`, `from`은 아님), `assumed_states[]`(`assumes`), `knowledge_gained[]`(`info`), 엔티티 선언(`description`·`traits[]`).
- **전제** = 그 항목의 `source_text`가 원문에서 가리키는 문장(공백 무시 부분 문자열로 찾은 문장 + 앞뒤 1문장). 원문에서 못 찾으면 표본에서 빼고 건수만 보고(인용 실재는 별도 신호, 환각 0.2~0.9% [기록]).
- **가설** = 구조값. 라벨러에게는 날것(`CHAR_004.possesses = OBJ_019 (카림의 수첩)`)과 레지스트리 이름으로 푼 형태(`마르타 — 소지 — 카림의 수첩`)를 **둘 다** 보여 준다. 라벨은 문장화 방식이 아니라 **항목**에 붙는다(뒤에 문장화를 바꿔도 라벨 유효).
- **출력 3클래스**: S 지지 · M 어긋남 · N 근거 없음. 주 표적은 **M**.

## 2. 라벨 지침 (판정 질문: "전제 문장이 이 구조값의 내용을 말하는가")

| 라벨 | 정의 |
|---|---|
| **S 지지** | 전제가 구조값의 내용을 말한다. 다른 표기('두 시 반'↔'2시 30분', '3킬로와트'↔'3kW'), 문장 안 대명사·생략 해소는 허용 |
| **M 어긋남** | 구조값의 어느 요소(주체·대상·사물 ID가 가리키는 것·수치·방향·시점·부정)가 전제와 **충돌**한다. 예: 마르타가 자기 수첩을 덮었는데 `카림의 수첩` 소지, 빚을 예금으로, 주는 쪽과 받는 쪽이 뒤바뀜 |
| **N 근거 없음** | 전제가 그 내용을 말하지 않는다 — 충돌도 지지도 아님. 한 단계를 넘는 추론, 전제에 없는 덧붙인 정보 |
| **?** | 판정 불가(근거 필수). 분모에서 빼고 건수 보고 |

우선순위: 한 요소라도 충돌하면 **M**, 충돌은 없는데 일부가 전제에 없으면 **N**, 전부 있으면 **S**.
판정하지 않는 것: 그 사실이 중요한지·지속되는지·서사에 쓰이는지(T6·T7의 유용성 질문은 여기 없다), 다른 칸이 운반하는지.
라벨러에게 숨기는 것: 층(의심/일반), 1단계 신호, 추출기 이름, 다른 라벨러의 라벨.

- **의심 층 150**: 1단계 신호가 켜진 항목 ∪ 값에 엔티티 ID가 들어가는 항목(`possesses`·`location`·관계 필드) ∪ T6 X 8건이 나온 사건의 같은 사건 항목. **일반 층 150**: 나머지에서 무작위.

## 4. 혼합 라벨 (사용자 결정, 11-07)

- **사용자 100 맹검**: 300 안에서 층별 50·50을 시드로 미리 뽑는다(누가 라벨하기 전에 고정). 사용자는 그 100만 라벨한다.
- **세션 300**: 별도 Claude 세션(T4 구현·설계와 무관한 맥락, 판단 세션 아님)이 300 전부를 사용자 라벨을 보지 않고 라벨한다.
- **세션 라벨 채택 기준(지금 고정)**: 사용자 100과 대조해 Cohen κ ≥ 0.70 **그리고** 사용자 M 대비 세션 M 재현율 ≥ 0.80 → 나머지 200의 세션 라벨을 평가 라벨로 쓴다(문서에 "세션 라벨, 사용자 100 대조 κ=…"로 표기). 미달 → 평가 라벨은 **사용자 100만**, 표본 확대 여부는 사용자 결정.
- 갈린 행은 사용자 라벨이 정답. 세션이 사용자 라벨을 본 뒤 고치지 않는다.
- **유료 LLM 규칙과의 관계(사용자 설명, 11-07)**: c52ae3d의 "무료 LLM만"은 **API 호출**(파이프라인·스크립트가 유료 API를 불러 데이터를 생성) 규칙이다. Claude Code 세션이 직접 읽고 판정하는 작업은 해당하지 않는다 — 세션 라벨은 허용된다. 검증기 저장소 T4 문서의 "유료 LLM으로 라벨을 만들지 않는다"도 API 호출 기준으로 읽는다.
- 규칙과 별개로 지키는 방법론:
  1. **사용자 100이 기준점.** 세션 라벨은 위 채택 기준으로 대조한 뒤에만 평가에 쓴다.
  2. **학습 라벨과 평가 라벨을 같은 판정자에게서 내지 않는다.** 세션 라벨을 학습에 쓰면(첫 실험은 안 씀, §7) 그 조건의 평가는 **사용자 라벨로만** 하거나, 평가용·학습용 세션 라벨을 다른 세션·겹치지 않는 표본으로 나눈다. 같은 판정자면 모델이 "그 판정자의 판정"을 배우고 같은 것으로 평가받는 순환이 된다.
  3. **출처 기록.** 세션 라벨은 스크립트처럼 재현되지 않는다 — 행마다 판정 세션 ID·모델·날짜·지침 판(이 문서 커밋 해시)을 남긴다.
- 주장 수위: 사용자 100 = "사람 라벨", 200 = "사용자 대조로 정확도를 잰 세션 라벨". "300 사람 라벨"이라고 쓰지 않는다.

## 5. 라벨 도구

- 검증기 저장소의 정적 HTML 한 장 + JSON(로컬 파일, 외부 전송 없음). `file://` 또는 `127.0.0.1`로만 연다.
- 행마다 전제 문장(인용 부분 강조)·구조값 두 형태·라벨 버튼(S/M/N/?)·메모 칸. 키보드 단축키. 진행률. 결과는 CSV로 내려받기.
- 층·신호·포함 확률·다른 라벨은 화면에 없다. 순서는 시드로 섞는다.

## 6. 기준선·모델·지표

- **B0** 1단계 신호(항목에 mark가 있으면 M 후보) · **B1** 영 학습: klue/roberta-base를 KLUE-NLI로만 미세조정(함의→S, 모순→M, 중립→N) · **B2** B1 + §7 학습 데이터.
- 주 지표: **M 탐지 PR-AUC**(M 대 나머지), **S 항목 오경보율 0.05에서 M 재현율**. 보조: 3클래스 macro-F1, 작품별 값. 모두 bootstrap 95%(층 보존 재표집, 1,000회, 시드 고정).
- 내부 목표(주장 아님): FPR 0.05에서 M 재현율 ≥ 0.5.
- 평가는 작품 단위 교차 적합: 평가 작품의 항목은 그 접기의 학습 데이터(교란 포함)에 쓰지 않는다.

## 7. 학습 데이터 (유료 LLM 없음)

- **구조 교란 → M**: 같은 회차 레지스트리 안에서 엔티티 교체(같은 종류), 사물 ID 교체, 수치 변경(단위 유지), 방향 뒤집기(주체↔대상), 위치 교체. 연산자는 이 다섯으로 고정.
- **전제 교체 → N**: 같은 조각에서 같은 엔티티가 나오는 다른 문장(어려운 음성) · 무작위 문장.
- **원 항목 → S(잡음 있음)**: 학습 작품의 원 항목. 잡음률은 평가 라벨의 M·N 비율로 보고.
- 템플릿 지름길 대책(J 실패 교훈): 문장화 변형 필드당 ≥ 3, 교란 비율·연산자별 성능 보고, 학습 곡선 25·50·100%. 교란 연산자는 **평가셋을 보고 고치지 않는다**(검증은 학습 작품 안의 검증 접기로).
- 선택: FABLES 번역(중간 단계) — 넣은 조건과 뺀 조건을 나란히. 첫 실험에는 넣지 않는다.
- 선택: 세션이 라벨한 실제 항목(학습 작품, 평가 표본과 겹치지 않게) — §4 방법론 2를 지키는 조건에서만, 학습 곡선이 데이터 부족을 가리킬 때. 첫 실험에는 넣지 않는다.
